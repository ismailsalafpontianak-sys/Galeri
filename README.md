# Galeri Penyimpanan Foto Video

Aplikasi galeri foto dan video untuk pemakaian pribadi.

- Pilih foto/video dari galeri HP — file asli disimpan utuh, ukuran tidak berubah.
- Tanggal, jam, dan hari dibaca otomatis dari file; lokasi bisa diisi manual.
- Cari dan filter berdasarkan nama, lokasi, dan hari.
- Detail tiap file menampilkan ukuran asli (byte), tipe, dan hash SHA-256, serta tombol unduh file asli.
- Data tersimpan lokal di perangkat (IndexedDB), bukan di server dan bukan di repositori ini.

Cara memakai: buka `index.html` di browser HP/laptop, atau buka lewat GitHub Pages setelah diaktifkan.
